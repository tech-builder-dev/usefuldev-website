Sprint Readiness for Jira — Documentation

Overview

Sprint Readiness for Jira helps teams identify common readiness problems in Jira sprints.

Running a readiness check

  1. Open the relevant Jira sprint.
  2. Open Sprint Readiness for the sprint.
  3. Run the readiness check.
  4. Review the readiness score and identified problems.
  5. Select a problem category to review affected Jira issues.

The readiness score is an aid for identifying issues that may need attention. It does not guarantee that a sprint is ready or that a sprint will succeed.

Readiness checks

The app can evaluate:

  • Missing estimates
  • Missing assignees
  • Missing descriptions
  • Missing acceptance criteria
  • Flagged or blocked issues
  • Unresolved linked dependencies
  • Missing parent relationships when configured
  • Unsuitable workflow statuses when configured

Project configuration

Jira project administrators can configure supported readiness settings from the app's project settings page.

Some checks require project-specific configuration and remain inactive until configured.

Data handling

Readiness analysis is performed on demand. Jira issue content and scan results are not persisted by UsefulDev in an external database. Project-level app configuration is stored using Atlassian Forge storage.
